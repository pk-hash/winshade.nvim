INTRODUCTION                                            *winshade-introduction*

Winshade automatically fades inactive windows in Neovim, helping you focus
on the active window by reducing visual clutter.

==============================================================================
REQUIREMENTS                                            *winshade-requirements*

- Neovim >= 0.8.0

==============================================================================
INSTALLATION                                            *winshade-installation*

Using lazy.nvim: >
    {
      "yourusername/winshade",
      config = function()
        require("winshade").setup()
      end,
    }
<

==============================================================================
CONFIGURATION                                          *winshade-configuration*

Setup with default options: >
    require("winshade").setup({
      fade_amount = 0.3,
      excluded_filetypes = {},
      excluded_buftypes = {},
      ignore_floating = true,
      floating_zindex_threshold = 50,
      debug = false,
      debounce_ms = 10,
      excluded_highlights = {
        "TabLineSel", "Pmenu", "PmenuSel", "PmenuKind",
        "PmenuKindSel", "PmenuExtra", "PmenuExtraSel",
        "PmenuSbar", "PmenuThumb", "StatusLine",
      },
    })
<

fade_amount                                          *winshade-fade_amount*
    Type: number (0.0 to 1.0)
    Default: 0.3

    Amount to fade inactive windows. Higher values mean more fading.

excluded_filetypes                            *winshade-excluded_filetypes*
    Type: table
    Default: {}

    List of filetypes to exclude from shading.
    Example: { "NvimTree", "neo-tree", "dashboard" }

excluded_buftypes                              *winshade-excluded_buftypes*
    Type: table
    Default: {}

    List of buffer types to exclude from shading.
    Example: { "terminal" }

ignore_floating                                  *winshade-ignore_floating*
    Type: boolean
    Default: true

    If true, floating windows will not be shaded.

floating_zindex_threshold                  *winshade-floating_zindex_threshold*
    Type: number
    Default: 50

    Exclude floating windows with z-index greater than this value.

debug                                                      *winshade-debug*
    Type: boolean
    Default: false

    Enable performance monitoring. When enabled, timing information is
    printed to |:messages|.
    Example output: "winshade: applied to 5 windows in 1.23ms"

debounce_ms                                          *winshade-debounce_ms*
    Type: number
    Default: 10

    Debounce time in milliseconds for window events. Lower values are more
    responsive but use more CPU. Higher values reduce CPU usage but may
    feel less responsive.

excluded_highlights                          *winshade-excluded_highlights*
    Type: table
    Default: { "TabLineSel", "Pmenu", "PmenuSel", ... }

    List of highlight groups to exclude from fading. By default, UI elements
    like popup menus and status lines are excluded to maintain readability.
    
    Example to add custom exclusions: >
        excluded_highlights = {
          "TabLineSel", "Pmenu", "StatusLine",
          "MyCustomHighlight",
        }
<

==============================================================================
COMMANDS                                                    *winshade-commands*

:WinshadeEnable                                              *:WinshadeEnable*
    Enable window shading.

:WinshadeDisable                                            *:WinshadeDisable*
    Disable window shading.

:WinshadeToggle                                              *:WinshadeToggle*
    Toggle window shading on/off.

==============================================================================
HEALTH CHECK                                                  *winshade-health*

Run the health check to verify installation and view current configuration: >
    :checkhealth winshade
<

The health check will display:
    - Neovim version compatibility
    - Plugin enabled/disabled status
    - Current configuration values
    - Excluded filetypes and buftypes
    - Floating window settings

==============================================================================
DEBUGGING                                                  *winshade-debugging*

Enable debug mode to see performance metrics: >
    require("winshade").setup({
      debug = true,
    })
<

When debug mode is enabled, timing information is printed to |:messages|
every time windows are shaded. Example output: >
    winshade: applied to 5 windows in 1.23ms
<

This is useful for:
    - Verifying the plugin is working
    - Identifying performance issues
    - Debugging unexpected behavior

To view messages: >
    :messages
<

==============================================================================
API                                                              *winshade-api*

require("winshade").setup({opts})                            *winshade.setup()*
    Initialize the plugin with configuration options.

    Parameters: ~
        {opts} (table) Configuration options

require("winshade").enable()                                *winshade.enable()*
    Enable window shading.

require("winshade").disable()                              *winshade.disable()*
    Disable window shading.

require("winshade").toggle()                                *winshade.toggle()*
    Toggle window shading on/off.
